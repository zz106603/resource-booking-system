# 예약 생성 화면 계획

**Goal:** 공간 선택·서울 시각 입력·검증·중복409 처리와 생성 결과를 제공한다.

**Architecture:** /reservations/new에서 기존 fetch·공간20개페이지를 사용한다. 상세 링크는 ?spaceId로 사전선택하고 해당 ID를 상세 API로 조회하므로 첫 페이지 밖 공간도 지원한다. 로컬 상태와 기존 CSS를 사용하며 라이브러리·백엔드 변경 없음.

**계약:** 표시/입력은 Asia/Seoul, datetime-local은 분 단위이며 브라우저 시간대와 무관하게 +09:00으로 전송한다. 예약자명 필수100자·양의 안전정수 공간ID·실제 날짜·시작미래·시작<종료를 검사하되 최종 판단은 서버다. 409 충돌 시 입력 유지·시간 변경 유도. 400필드/비즈니스오류·404·503·네트워크도 안내. POST자동재시도 없음·중복제출 차단. 성공 시 영수증 형태의 ID·선택공간·시각 표시, 재예약은 명시적으로 새 폼을 연다. 목록/취소 미구현.
