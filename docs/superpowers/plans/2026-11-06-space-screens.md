# 공간 등록·상세 화면 계획

**Goal:** 기존 목록에 등록·상세 화면을 연결하고 등록 성공 시 실제 ID로 이동한다.

**Architecture:** Vue Router /spaces/new·/spaces/:id, 기존 fetch 계층과 Space 응답 검증을 확장한다. 로컬 폼 상태와 서버 fieldErrors를 사용한다. 별도 의존성·백엔드 변경 없음.

**계약:** 이름 공백 불가·100자, 설명 선택·2000자, 수용 인원 양의 32비트 정수. 입력 문자열은 임의 trim하지 않고 보존한다. 상세 ID는 양의 안전 정수까지만 지원한다. 등록 중 중복 제출 금지·자동 재시도 없음. 상세는 경로 변경과 이탈 시 이전 요청을 취소한다. 시간대 Asia/Seoul. 예약 화면은 제외.

- [x] API·입력 검증·필드 오류·등록 후 이동·상세 성공/404/실패/ID 변경 테스트를 먼저 작성하고 실패 확인.
- [x] API/폼/상세/Router 및 목록 링크와 CSS 구현, 테스트 통과.
- [x] 실행·요구사항·아키텍처·API 문서 갱신.
- [x] lint·타입·전체 프런트엔드 테스트·빌드 및 가능한 격리 PostgreSQL·실제 API·프록시 HTTP 검증. 총33개 통과, 실제 API/임시DB 검증 후 정리.
- [x] 독립 리뷰·타당한 지적 처리·문서/범위 검사·검증 서버 정리. Critical·Important 없음, Minor 1건은 늦은 응답 회귀 테스트 후속 보강으로 기록. 상세는 [frontend-space-screens.md](../../frontend-space-screens.md) 참조. 커밋·push 금지.

브라우저는 이전 정책 차단 및 미검증 유지 지시에 따라 호출하지 않고 렌더링·클릭·키보드·반응형 동작은 미검증으로 구분한다.
