# Resource Booking 프런트엔드

Vue 3·TypeScript·Vite SPA. 공간 목록·페이지 조회·등록·상세와 예약 생성·목록·취소를 제공한다. 화면 계약·검증은 [공간 화면](../docs/frontend-space-screens.md), [예약 생성 화면](../docs/frontend-reservation-create.md), [예약 목록·취소 화면](../docs/frontend-reservation-list.md)을 따른다.

설치·개발 서버·검증 명령·실제 연동 범위는 [프런트엔드 실행 안내](../docs/frontend-setup.md)를 따른다. 작업 지침은 [AGENTS.md](AGENTS.md)에 있다.

Node 버전은 `.nvmrc`, 재현 가능한 패키지 버전은 `package-lock.json`을 따른다. `frontend/`에서 `npm ci` 후 `npm run dev`로 실행한다.
