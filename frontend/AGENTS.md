# 프런트엔드 작업 지침

- 루트 AGENTS.md의 Git·검증·독립 리뷰 규칙을 함께 따른다.
- Vue SFC, Composition API, `<script setup lang="ts">`를 사용한다. 화면 상태는 로컬에서 시작하고 실제 재사용 필요가 생기면 공통화한다.
- HTTP 요청과 계약 타입은 `src/api/`에서 관리한다. 백엔드 API 문서·OpenAPI와 다르면 임의로 계약을 바꾸지 않는다.
- 시각 표시는 Asia/Seoul로 통일하고 화면에 시간대를 명시한다. API 전송 시 오프셋 포함 ISO 시각을 사용하며 저장된 시각 문자열을 임의로 다시 쓰지 않는다.
- 로딩·빈 결과·오류·제출 중 상태를 구분하고 label·키보드 조작·상태 안내를 제공한다. 선택 필터의 미지정과 빈 문자열을 구분한다.
- 테스트 설명은 조건과 기대 결과가 드러나는 한글로 작성한다. 모킹 결과를 실제 서버 연동 성공으로 보고하지 않는다.
- 실행·검증 명령과 상세 범위는 [../docs/frontend-setup.md](../docs/frontend-setup.md)를 따른다. 실제 필요 없이 상태 관리·HTTP·UI 라이브러리를 추가하지 않는다.
